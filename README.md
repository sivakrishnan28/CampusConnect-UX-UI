# CampusConnect – UX/UI Mobile App Wireframing

CampusConnect is a student-focused mobile application concept designed to help college students manage their academic activities from one centralized platform.

## 📱 Project Overview

College students often manage their timetable, assignments, deadlines, study materials, and other academic information across multiple platforms.

CampusConnect aims to simplify this experience by bringing essential academic information together in a simple and accessible mobile interface.

## 🎯 Project Objective

To design a simple and user-friendly mobile application that helps students:

- View their daily timetable
- Track assignments
- Monitor deadlines
- Access study materials
- Manage their profile
- Navigate academic information from one centralized dashboard

## 🧠 Design Thinking Process

The project follows the five stages of Design Thinking:

1. Empathize
2. Define
3. Ideate
4. Prototype
5. Test

## 🔎 User Research

Preliminary research focused on common academic-management challenges faced by college students.

### Key Insights

- Academic information can be scattered across multiple platforms.
- Assignment deadlines can be difficult to track.
- Students need quick access to their daily timetable.
- Study materials should be easy to locate.
- A centralized dashboard can simplify navigation.

## 🔄 User Flow

The primary user journey is:

Splash → Login → Home Dashboard

From the dashboard, users can navigate to:

- Timetable
- Assignments
- Study Materials
- Profile

Users can also open an assignment to view its detailed information.
